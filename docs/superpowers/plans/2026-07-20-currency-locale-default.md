# Single-Default Currency/Locale Consolidation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `DefaultLanguage` config, add `Currency` to `PaymentCapture`, fix `line_items.currency` schema inconsistency, delegate `Variant.AllowedCurrencies` to `SystemCurrency`, remove dead `store_currency` permission.

**Architecture:** 5 independent sections — DefaultLanguage mirrors existing DefaultCurrency pattern (appsettings → ISystemInfo → constant fallback). PaymentCapture gets Currency via existing PaymentConstant. LineItem config fixed using existing OrderConstant. Variant delegates to SystemCurrency.Supported. Dead permission removed.

**Tech Stack:** .NET 10, EF Core + Npgsql, C# (TreatWarningsAsErrors=true)

## Global Constraints

- `TreatWarningsAsErrors=true` — zero warnings on `dotnet build`
- All constants use existing `PaymentConstant`/`OrderConstant`/`SystemCurrencyConstant` — no magic values
- Migrations generated by EF — no manual SQL
- `dotnet test service/Api/tests/Module.UnitTests` must pass after each task
- Commit after each task with conventional commit message
