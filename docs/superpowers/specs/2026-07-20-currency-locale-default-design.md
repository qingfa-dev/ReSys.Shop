# Single-Default Currency/Locale Consolidation

**Constraint:** en-US / USD only. No multi-currency or multi-language support.

## Section 1: DefaultLanguage — Configurable via appsettings

Mirror the existing `DefaultCurrency` pattern.

| File | Change |
|---|---|
| `SystemCurrencyConstant.cs:17` | Add `public const string Language = "en";` to `Defaults` class |
| `ISystemInfo.cs:36` | Add `string DefaultLanguage { get; }` |
| `SystemInfo.cs:26` | Add `DefaultLanguage => configuration["System:DefaultLanguage"] ?? SystemCurrencyConstant.Defaults.Language` |
| `appsettings.json:181` | Add `"DefaultLanguage": "en"` under `"System"` |

Constants: `SystemCurrencyConstant.Defaults.Language` is the fallback (hardcoded "en"). `appsettings.json` overrides it if present. No new classes, no new files.

## Section 2: PaymentCapture.Currency — Add Currency Column

| File | Change |
|---|---|
| `PaymentCapture.cs:L14` | Add `public string Currency { get; set; } = PaymentConstant.Defaults.Currency;` after `Amount` |
| `PaymentRecordConfiguration.cs` | Add `builder.Property(x => x.Currency).IsRequired().HasMaxLength(PaymentConstant.Constraints.MaxCurrencyLength).HasDefaultValue(PaymentConstant.Defaults.Currency)` |
| `PaymentStoreMapping.cs:L26,43` | Replace `Currency = string.Empty` with `Currency = payment.Currency` |
| Migration | Generated by EF — `varchar(3)` column with `"USD"` default |

Constants reuse: `PaymentConstant.Defaults.Currency` (already `= SystemCurrencyConstant.Defaults.Code`) and `PaymentConstant.Constraints.MaxCurrencyLength` (already `= SystemCurrencyConstant.Constraints.MaxCodeLength`). Zero magic values.

## Section 3: line_items.currency — Schema Consistency Fix

`line_items.currency` is `type:"text", nullable:false, no default` — inconsistent with `orders.currency` (`varchar(3)`, default `"USD"`).

| File | Change |
|---|---|
| `LineItemConfiguration.cs` | Add `builder.Property(x => x.Currency).IsRequired().HasMaxLength(OrderConstant.Constraints.MaxCurrencyLength).HasDefaultValue(OrderConstant.Defaults.Currency)` |
| Migration | EF generates `ALTER COLUMN "currency" TYPE varchar(3)`, `SET DEFAULT 'USD'` |

Constants reuse: `OrderConstant.Constraints.MaxCurrencyLength` (already `= SystemCurrencyConstant.Constraints.MaxCodeLength`) and `OrderConstant.Defaults.Currency` (already `= SystemCurrencyConstant.Defaults.Code`).

## Section 4: Variant.Constant — Delegate to SystemCurrency

`Variant.Constant.cs:L45` hardcodes `["USD","EUR","GBP","JPY","CAD"]` independently of `SystemCurrency.Supported`.

Replace with: `public static readonly string[] AllowedCurrencies = [.. SystemCurrency.Supported.Keys];`

Single source of truth — `SystemCurrency.Supported` is the system-wide currency registrar.

## Section 5: Remove Dead store_currency Permission

Permission defined in `PermissionContext.cs:L190-191` and `ConfigurationFeatureMetadata.cs` but no admin endpoint or UI implements it. Single-currency means no admin currency configuration exists to guard.

Remove `StoreCurrency` from both files.
