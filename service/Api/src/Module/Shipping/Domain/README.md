# Shipping Domain

DDD domain models: Shipments (with events), ShippingMethods, ShippingRates.

## Aggregates

| Aggregate | Path | Purpose |
|-----------|------|---------|
| Shipments | `Shipments/` | Shipment tracking with events |
| ShippingMethods | `ShippingMethods/` | Available shipping methods |
| ShippingRates | `ShippingRates/` | Computed shipping rates |
