# Shipping Module

The Shipping module manages the complete shipment lifecycle within the ReSys e-commerce platform. It provides domain models, state machine transitions, and strategy-pattern calculators for determining shipping costs — all ported directly from the Spree Ruby SDK to idiomatic C# 13 / .NET 10 domain code. The module follows the sealed partial entity pattern with concern-per-file partials, ensuring each aspect (extensions, validation, constants, results, loggers, custom events, webhooks, state machine) remains focused and independently maintainable.

Core capabilities include: (1) a **Shipment state machine** supporting Pending → Ready → Shipped → terminal transitions with Cancel and Resume operations, (2) **six calculator strategies** (FlatRate, PerItem, FlatPercentItemTotal, FlexiRate, PriceSack, DigitalDelivery) implementing the `IShippingCalculator` interface with eligibility guards, (3) **zone-based geographic matching** via Country and State kind zones with polymorphic ZoneMembers, and (4) **shipping method configuration** with calculator type assignment, tax category association, and tracking URL templates. The shipment entity exposes well-defined extension methods that return `Result` monads for consistent error handling throughout the domain layer.

The module is designed to be consumed primarily by the Ordering module during checkout — where shipping rates are calculated, rates are selected, and shipments transition through their lifecycle — and by admin features for shipment management and fulfillment. All 56+ domain files are annotated with Code Commenting Standard v3.0 CAT labels across all ten categories, and the state machine invariants and calculator strategy patterns are documented in the accompanying `README.xml`.
