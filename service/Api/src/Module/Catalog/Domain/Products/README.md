# Products Domain

Product catalog aggregates: Products, Variants, Images, Prices, Embeddings, Prototypes, Classifications.

## Aggregates

| Aggregate | Purpose |
|-----------|---------|
| Product | Product aggregate with variants and classifications |
| Variant | SKU with images, prices, embeddings, option values |
| Image | Product variant images with upload/download |
| Price | Variant pricing with currency |
| Embedding | ML-generated visual embedding vectors |
| Prototype | Product template for efficient variant creation |
| Classification | Product-to-taxon classification mapping |
