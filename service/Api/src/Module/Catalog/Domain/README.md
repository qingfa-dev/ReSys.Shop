# Catalog Domain

DDD domain models for product catalog: Products, Variants, OptionTypes, Taxonomies, and Taxons.

## Aggregates

| Aggregate | Path | Key Concepts |
|-----------|------|-------------|
| Products | `Products/` | Products, Variants, Images, Prices, Embeddings, Prototypes, Classifications |
| OptionTypes | `OptionTypes/` | OptionTypes, Values |
| Taxonomies | `Taxonomies/` | Taxonomies, Taxons, Rules |
