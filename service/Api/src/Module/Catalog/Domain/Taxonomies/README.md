# Taxonomies Domain

Hierarchical taxonomies and taxons with classification rules for products.

## Aggregates

| Aggregate | Purpose |
|-----------|---------|
| Taxonomy | Top-level category (e.g., "Clothing", "Electronics") |
| Taxon | Hierarchical node with auto-classification rules |
| Rule | Classification rule for product assignment |
