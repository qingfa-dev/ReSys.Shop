# Storefront · Products

Public product browsing: search, filter, detail, similar products, image search.

## Endpoints

| Feature | Key Commands |
|---------|-------------|
| Search | Text search with filters |
| Filter | Category/price/attribute filtering |
| Detail | Single product with variants |
| Similar | Vector-based visual similarity |
| Related | Related product recommendations |
| NewArrivals | Recently added products |
| Availability | Stock availability check |
| SearchByImage | Reverse image search via embeddings |
