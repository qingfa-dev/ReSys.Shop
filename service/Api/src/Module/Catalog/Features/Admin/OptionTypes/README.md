# Admin · OptionTypes

Admin CRUD operations for product option types and values.

## Endpoints

| Command | Route | Purpose |
|---------|-------|---------|
| Create | POST `/admin/option-types` | Create option type |
| Update | PUT `/admin/option-types/{id}` | Update option type |
| Delete | DELETE `/admin/option-types/{id}` | Soft-delete option type |
| Get | GET `/admin/option-types` | List/paged option types |
| OptionValues CRUD | `/admin/option-types/{id}/values` | Manage option values |

## Category

Catalog · Admin
