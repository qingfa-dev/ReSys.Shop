# Admin · Products

| Feature | Key Commands |
|---------|-------------|
| Products | Create, Update, Delete, Get, Activate, Discontinue |
| Variants | Add, Update, Delete, List |
| Images | Upload, Download, Update, Delete, ListByVariant, GetById |
| Embeddings | Generate via inference sidecar |
| Prices | Set, Remove, Get, Sync |
| Classifications | Assign, Revoke, Get, Sync |
| OptionTypes | Assign, Revoke, Get, Sync |
