# Storefront · Cart

Customer shopping cart: create, add/remove items, checkout, validate, currency change.

## Endpoints

| Feature | Key Commands |
|---------|-------------|
| Cart | CreateCart, DeleteCart, Get, EmptyCart, AssociateCart |
| Items | AddItem, RemoveItem, UpdateItemQuantity |
| Checkout | AdvanceCheckout, UpdateCheckout, Checkout, ValidateCheckout |
| Shipping | SelectShippingRate |
| Currency | ChangeCurrency |
